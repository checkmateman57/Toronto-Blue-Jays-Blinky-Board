# Toronto Blue Jays Blinky Board
I created a blinky board as per the starter guide's manual, and have the custom shape of the Toronto Blue Jays logo. I chose this design because I really enjoyed their playoff run last year and wanted to honour them, which is why I have pictures of them being ALCS champs on the silkscreen.
